## 2. Structural Mechanisms / 3つの主要メカニズム

### 2.1 The Ring Singularity as a "Zero-Seat" Anchor (ゼロ席としての特異点リング)
* **Why a Ring, Not a Point?** Under continuous 3D metrics, collapse leads to a zero-dimensional point of infinite density. In 4D quaternion space ($S^3$), rotational symmetry fixes an invariant great circle ($S^1$). This circle serves as the **Zero-Seat (ゼロ席)**: an algebraic origin where radial distance vanishes while cyclic angular order ($C_n$) remains intact.
* **Principal Ideal Condensation:** Infalling matter is stripped of external gauge couplings via structural apoptosis and rounded into a single, maximally dense **principal ideal** anchored on this zero-seat.

* **点ではなく「リング」である理由：** 4次元四元数空間（ $S^3$ ）において回転対称性を保つと、不変な大円（ $S^1$ ）が残ります。これが**ゼロ席（Zero-Seat）**であり、動径方向の計量がゼロに潰れても $C_n$ の巡回順序そのものは破壊されない絶対的な固定アンカーとして機能します。

### 2.2 Ergosphere & Horizon as Orthogonal Projection ($P_1 + P_2 = 1$)
* **Frame-Dragging as Chiral Shift:** Outside the static limit, 3D conjugation ($q x q^{-1}$) transitions into left-isoclinic quaternion multiplication ($q_L \cdot x$), locking local $C_n$ frames to the black hole's spin.
* **Hawking Radiation via $P_1 P_2 = 0$:** At the event horizon boundary, the projection operator splits every state into an interior bound component ($P_1$) and an exterior orthogonal complement ($P_2 = 1 - P_1$). The minimal phase residues unable to lock into the interior principal ideal are ejected outward along $P_2$ as thermalized radiation (Hawking radiation) and collimated polar jets along the invariant axis.

* **エルゴ球と事象の地平面の射影分離：** 静止限界の内側では通常の3次元回転（ $q x q^{-1}$ ）が左アイソクリニック回転（ $q_L \cdot x$ ）へと移行し、局所フレームが強制的に回転へ引きずられます。事象の地平面では直交射影 $P_1 + P_2 = 1$ が作動し、内部の単項イデアル（ $P_1$ ）に回収されなかった最小位相剰余が直交補空間（ $P_2$ ）へ切り離され、ホーキング放射や回転軸方向のジェットとして排出されます。

### 2.3 Cosmic Web Filaments as $S^3$ Projections (銀河フィラメント網の $S^3$ 幾何学)
* **Nodes and Voids:** Supermassive black holes at galactic centers act as discrete anchor nodes (zero-seats) embedded in a closed $S^3$ hypersphere.
* **Stereographic Mapping:** When the discrete polytope tiling of $S^3$ (such as the 24-cell / 600-cell cellular network) is stereographically projected onto 3D space, the Voronoi cells appear as vast cosmic voids, while the 1D edges connecting the anchor nodes manifest as **galactic filaments**.

* **ノードとボイドの双対性：** 各銀河中心の巨大ブラックホールは、閉じた3次元球面 $S^3$ 上に配置された離散的なアンカーノード（ゼロ席）です。 $S^3$ 上の多胞体セル分割（正24胞体・正600胞体ネットワーク）を3次元空間へ立体射影すると、セルの内部が空隙（ボイド）となり、アンカー同士を結ぶ1次元の辺が**銀河フィラメント網**として立ち現れます。
